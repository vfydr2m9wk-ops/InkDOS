# InkDOS v1.0.0-beta.3 — 1.0 Beta 3

Beta 3 establishes the lean current-state baseline for InkDOS. It completes the product-identity transition, removes active-tree historical baggage, compacts the updater state and consolidates visual correction layers without intentionally expanding the editor feature set.

The supported product remains six local-first workspaces: Documents, Spreadsheets, Presentations, PDF, Plain Text and EPUB Reader. Existing format, recovery and generated-copy safety contracts remain release gates.

The next planned milestone is `1.0.0-rc.1` after real-device and browser evidence confirms this baseline.
