# InkDOS releases (legacy)

These are the versions InkDOS published on GitHub until 2026-10-10. Their tags and GitHub releases were removed so
no one downloads builds that no longer reflect the project; their notes and small files are kept here for reference.
Large Linux AppImage installers (about 85 MB each) were not kept; the code of every version stays in the git history.

This branch also keeps the project as it was before Firefox support was dropped (see SUPPORT.md on main).
