# Project status

Release: **InkDOS 2.0.5**

Six installed independent workspaces: Documents, Spreadsheets, Presentations, Plain Text, EPUB Reader and PDF Workspace. InkDOS 2.0.5 preserves the six app runtimes and the 2.0.4 Share implementation while restoring Home/manifest metadata used for standalone Web App installation on WebKit-compatible hosts. PDF retains the user-accepted P4.2 functional baseline. See `PDF-CLOSURE-AUDIT.md` for its verification scope.
