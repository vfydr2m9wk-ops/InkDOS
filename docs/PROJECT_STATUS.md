# Project status

Release: **InkDOS 2.0.6**

Six installed independent workspaces: Documents, Spreadsheets, Presentations, Plain Text, EPUB Reader and PDF Workspace. InkDOS 2.0.6 preserves the Web App compatibility restored in 2.0.5 and the six-app Share behavior from 2.0.4. Plain Text no longer exposes the production global runtime-error banner, and its self-contained `index.html` is now deterministically built and checked against its modular template, styles and JavaScript sources. PDF retains the user-accepted P4.2 functional baseline. See `PDF-CLOSURE-AUDIT.md` for its verification scope.
