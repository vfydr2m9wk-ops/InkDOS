# InkDOS icon system

The `0.19.4.11` icon family uses a shared rounded-square silhouette, minimal
geometry, and consistent optical weight.

| Symbol | Color | Meaning |
| --- | --- | --- |
| Quill and inkwell | Ink navy | InkDOS suite |
| Text document | Blue | Documents |
| Table grid | Green | Spreadsheets |
| Presentation board | Orange | Presentations |
| Page with PDF tab | Red | PDF |
| Open book | Purple | Planned EPUB reader |
| Notebook | Yellow | Planned TXT editor |

Each symbol is supplied as SVG for interface use and 512×512 PNG for launchers
and the web-app manifest. The primary InkDOS icon also has a multi-resolution
ICO file. No font files are included.
