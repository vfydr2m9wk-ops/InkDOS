# Migration to InkDesk

InkDesk is the continuation of the earlier codebase under a distinct, searchable identity. The migration is a branding and repository-governance change, not a rewrite.

The initial public InkDesk version is `0.19.0-beta`, preserving technical continuity while reserving `1.0.0` for broader browser/device validation. Existing supported files require no data migration. Internal persisted keys should only be renamed with an explicit migration or fallback.
