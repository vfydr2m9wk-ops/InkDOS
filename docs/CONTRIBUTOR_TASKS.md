# Contributor Task Map

Good first contributions should be small and testable.

## Documentation

- reproduce a known limitation with a public sample;
- improve a compatibility explanation;
- document a font substitution;
- test one browser/host combination.

## Testing

- add a minimal synthetic OOXML fixture;
- add a regression test for a fixed bug;
- improve validation error messages;
- create a deterministic screenshot protocol.

## Code

- isolate a parser assumption behind a small helper;
- remove duplicated logic;
- replace silent exception handling with diagnostics;
- fix one clearly scoped rendering bug.

Large feature proposals should begin as an issue with a use case and test plan.
