# InkDOS 2.3 Goal 1 Format Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete Goal 1 by preserving approved raw-text formats in Plain Text and adding loss-aware CSV/TSV editing to Spreadsheets with same-format save by default.

**Architecture:** Keep format responsibilities workspace-local. Plain Text uses its existing policy/controller path. Spreadsheets gains one isolated delimited-text codec used by file-open and save controllers; `WorkbookSession.sourceKind` remains the source-format authority. XLSX-only feature use is guarded before mutation and offers explicit conversion rather than silently changing format.

**Tech Stack:** Static HTML/CSS/JavaScript, Python contract tests, Node-based JavaScript behavior probes where needed, existing LocalXLS/LocalXLSX engines.

**Spec:** `docs/superpowers/specs/2026-09-13-inkdos-2.3-design.md`

## Global Constraints

- Fixed goal order: Goal 1 before Goals 2–4.
- Plain Text remains raw text and preserves approved original extensions.
- CSV/TSV belong only to Spreadsheets.
- CSV/TSV parsing must handle quotes, embedded delimiters/newlines, BOM/encoding, and leading-zero strings.
- Save CSV/TSV back to the original format by default.
- Never silently convert to XLSX; warn and offer conversion before an XLSX-only feature is applied.
- No Home redesign, telemetry, backend, or new network path.
