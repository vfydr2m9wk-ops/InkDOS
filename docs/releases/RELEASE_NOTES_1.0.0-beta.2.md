# InkDOS v1.0.0-beta.2 — 1.0 Beta 2

Maintenance release focused on the permanent InkDOS update pipeline and current
project identity. It preserves the feature-frozen 1.0 beta application scope.

- Migrates the incremental update contract from InkDesk naming to InkDOS.
- Preserves internal sequence history and advances the public beta from updater-bootstrap sequence 58 to sequence 59.
- Adds deterministic package generation and per-file SHA-256 contracts.
- Keeps workflow files outside update ZIPs and requires manual bootstrap for workflow changes.
- Updates public package/license/release identity, switches canonical repository and Pages metadata to `vfydr2m9wk-ops/InkDOS`, and removes the obsolete `InkDesk.html` redirect.
- Introduces no new editing feature and does not remove PPT/PPTX support.
