PDF tools Beta

Experimental tools for the web edition. Everything runs in this browser: files, certificates and passwords never leave your device unless you send a file to the official ITI validator yourself.

No PDF open

Recognises the text of scanned pages and adds an invisible text layer, so the PDF can be searched and copied. The pages look the same.

Draw or choose a signature image, then click on the page where it goes. A visual signature is a picture: for legal validity use the digital signature.

Signs the PDF in the PAdES format with your valid A1 certificate (.pfx/.p12). The signature is added as an incremental update, so earlier signatures stay valid. Place any visual signature first.

Locking certifies the document: any later change (text, pages, annotations or another signature) makes PDF readers report the signature as invalid. Only the first signature can lock a document.

Adds the ICP-Brasil policy PA_PAdES_AD_RB v1.1 to the signature. Use it only with an ICP-Brasil certificate, and confirm the result on the official ITI validator.

Checks, on this device, that each signature matches the document, that the document was not changed afterwards and whether the certificate chain leads to an ICP-Brasil root. Revocation is not checked here: use the official validator for the complete validation.

    Official validation (ITI)

    This opens validar.iti.gov.br, the Brazilian government's signature validator, in a new tab. InkDOS sends nothing: you choose the file on the ITI site.

    On that site the whole document (content, signatures and metadata) is sent to the government's servers to be validated. Do not continue with a document that must not leave this device.

    Validate the exact file you will deliver: if you signed it here, download it first.
