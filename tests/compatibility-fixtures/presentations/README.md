# Presentation compatibility fixtures

These synthetic files were created for repository regression testing and contain no private user data.

- `era1_office_97_2003_legacy.ppt` — real OLE binary PPT used to verify controlled rejection.
- `era2_office_2007_2013_baseline.pptx` — baseline text, bullets, image, table, layouts and master.
- `era3_office_2016_365_modern.pptx` — cropped image, grouped shapes, cached chart, notes and transition.

The fixtures may be redistributed with the project under the repository license.
